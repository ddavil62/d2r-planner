# GitHub Pages deployment

The site is deployed automatically from `main` by
`.github/workflows/deploy-pages.yml`.

- Site URL: `https://ddavil62.github.io/d2r-planner/`
- Build command: `npm run build`
- Build output: `dist`
- Vite base path: `/d2r-planner/`

The published site is public. Build data is saved only in the visitor's browser
unless they explicitly copy and share a build code.
