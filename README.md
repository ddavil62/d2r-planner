# 성역의 설계서

Diablo II: Resurrected `악마술사의 군림` 3.3 비래더를 기준으로 한 개인용 빌드 플래너입니다.

현재 우선 지원 직업은 네크로맨서와 원소술사입니다. 스킬/능력치 예산, 장비 옵션 합산,
저항과 주요 브레이크포인트, 전체 아이템 검색, 인벤토리, 로컬 저장과 URL 공유를 브라우저에서 처리합니다.

## 구현된 범위

- 설치된 `3.3.93847` 게임 데이터로 검증한 두 직업의 60개 기술과 선행 조건
- 레벨 1~99, 퀘스트 기술/능력치/저항 보너스, 난이도 저항 페널티
- 활성 고유 403개, 세트 135개, 룬어 99개의 원본 카탈로그 검색, 주요 옵션 합산과 파밍 목록
- 대표 장비의 즉시 착용·교체 영향 계산, 후보 아이템 원본 옵션 비교
- 무기 세트 I/II, 10×4 부적·호라드림의 함 배치, 레벨 비례 아이템 옵션
- 생명력, 마나, 능력치, 저항, 패캐/패힛/패블럭, 매찬 등 합산
- 네크 3종과 소서 3종의 합법적인 추천 빌드 골격
- 직업별 프레임과 다음·권장 브레이크포인트 부족 수치
- 브라우저 보관함, 장비·기술 상세 비교, 변경 이력과 압축 URL 공유
- 데스크톱과 모바일 반응형 화면

## 정확도 경계

현재 버전은 빌드 구성과 옵션 합산에 집중합니다. 스킬별 실제 피해량, 적 저항 적용,
공격 속도 프레임, 소환물의 상세 전투 성능은 아직 계산하지 않습니다. 변동 옵션을 가진
프리셋은 별도 표기가 없으면 좋은/최대 수치를 사용하며 실제 아이템과의 차이는 `추가 보정`에서
입력할 수 있습니다.

전체 카탈로그는 능력치, 생명력·마나, 저항, 기술, 패캐·패힛·패블럭·공속·달리기,
매찬·골찬과 주요 방어 옵션을 계산합니다. 피해 유형, 발동 기술, 오라처럼 현재 요약 모델에
없는 원본 옵션은 아이템 카드에는 표시되지만 합계에는 아직 포함되지 않습니다.

```powershell
npm install
npm run dev -- --host
```

검증은 `npm test`, `npm run build`, `npm run test:e2e`로 실행합니다.
